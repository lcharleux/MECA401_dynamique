# Mécanique dynamique

Bienvenue dans le cours de **mécanique dynamique** du module MECA401.

Ce site est en cours de construction. Les chapitres, exercices et notebooks
seront ajoutés progressivement dans les sections du sommaire.

## Organisation du cours

Les contenus Markdown seront placés dans `src/dynamique/` et les activités
Python dans `src/notebooks/`. Pour ajouter une page, créer le fichier puis
l’inscrire dans le sommaire de `myst.yml`.

```{tip} Développer localement
Utiliser `make preview` pour obtenir un aperçu avec rechargement automatique.
```
